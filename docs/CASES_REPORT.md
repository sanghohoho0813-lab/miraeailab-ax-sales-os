## 2. 사례 추천 — 새 조합 규칙

```
같은 업종 Pool (FILTER)  →  점수순 (SCORE)  →  조합 (COMPOSE)
  1) 10억 이내 사례를 점수순으로 3개까지 먼저 확보 (있는 만큼 — 없으면 억지로 채우지 않는다)
  2) 남은 자리는 점수순, 단 수십억(20억 이상) 조달 사례는 2개까지만
  3) 화면 순서는 다시 점수순 — 조합은 "무엇이 들어가나", 순서는 "얼마나 비슷한가"
```

- 카드마다 **규모 배지**: `10억 이내` / `10~20억` / `수십억 조달` / `규모 미공개`. 대표 앞에서 "우리 규모 얘기인가" 를 한눈에.
- 전략 화면 사례 섹션 부제: "같은 업종에서 골랐고, 10억 이내로 조달한 사례를 먼저 보여 드립니다."
- 결과 화면 "참고할 실제 사례" 도 같은 5개(내가 고른 사례 우선).
