# REQUEST 11 — 실사용 고도화: "다음에 뭐 하지?" 를 시스템이 답한다

작업 브랜치 `claude/festive-babbage-uj6ugd`. **마이그레이션 변경 없음** — 이미 있는 고객·미팅·2차 제안 요청 데이터로 계산한다.

---

## 0. 분석 — 실제로 막히던 지점

전체 화면을 컨설턴트의 하루 순서(등록 → 전략 → LIVE → 분석 → 2차 제안 요청 → 다음 미팅)로 직접 돌려 봤다.
화면 오류는 0건이었다. 문제는 **화면마다 "이 고객 다음에 뭐 하지?" 에 다르게 답하고 있었다**는 것이다.

| 증상 | 실제 영향 |
|---|---|
| 분석까지 끝난 고객을 다시 열면 주 버튼이 **"미팅 시작"** | 누르면 새 미팅이 생기고, 정작 2차 제안 요청은 안 보내진 채 남는다 (돈이 새는 지점) |
| 홈에 **중단된 미팅 · 요청 안 보낸 분석**이 없음 | 컨설턴트가 기억해서 찾아가야 했다 |
| 일정이 지났는데 기록이 없는 미팅이 **"날짜 미정"** 으로 분류 | 놓친 미팅이 조용히 묻혔다 |
| 고객 검색이 **회사명만** | 컨설턴트는 "박 대표네", "9911 그 번호" 로 기억한다 |
| 고객 목록에 상태 필터·정렬 없음, 열었다 돌아오면 검색어가 사라짐 | 고객이 수십 명을 넘으면 매번 다시 찾는다 |

---

## 1. 업무 상태 엔진 — 판단을 한 곳으로 (`src/engine/workStatus.ts`)

고객 한 곳마다 **단계 · 이유 한 줄 · 다음 행동 하나 · 우선순위**를 계산한다. 홈 · 고객 · 미팅 · 미팅 전략 화면이 모두 이것만 쓴다.

| 순위 | 단계 | 이유 (화면 문구) | 다음 행동 |
|---|---|---|---|
| 0 | 미팅 중 | 중단된 미팅입니다 — 기억이 흐려지기 전에 마무리하세요 | 이어서 진행 → LIVE |
| 1 | 분석 완료 | 2차 제안 요청을 아직 보내지 않았습니다 (철회 건은 "고쳐서 다시 보내세요") | 2차 제안 요청 → 결과 화면 |
| 2 | 제안 준비완료 | 2차 제안이 준비됐습니다 — 2차 미팅 일정을 잡으세요 | 제안 확인 |
| 3 | 지난 미팅 | N일 전 미팅이 기록되지 않았습니다 — 기록하거나 일정을 바꾸세요 | 미팅 기록 |
| 4 | 오늘 미팅 | 오늘 HH:mm 미팅 | 전략 보고 시작 |
| 5 | 예정 · 6 준비 · 7 전달 완료 | — | 전략 보기 / 요청 상태 |

0~4 가 "지금 할 일". 같은 단계 안에서는 오래 묵은 것이 먼저. 전달 뒤에 새 미팅 일정이 잡히면 그 일정이 다음 할 일(2차 미팅).

## 2. 화면

- **홈** — "지금 할 일 N건" 큐 하나. 줄 전체가 다음 행동 링크(폰에서 엄지로 어디를 눌러도 된다). 그 아래 다가오는 미팅 · 2차 제안 진행 상황.
- **고객** — 회사명 · 대표자 · 전화번호(하이픈 무시, 뒷자리 3자 이상) · 업종 메모 · 메모 통합 검색.
  상태 칩(전체/할 일/예정·준비/전달 완료, 건수) · 정렬(최근 활동/미팅 일시/이름). **검색어·상태·정렬은 주소에 남아** 고객을 열었다 돌아와도 그대로.
  다음 행동이 "전략 보기" 뿐인 줄은 버튼을 두지 않는다(줄을 누르는 것과 같다 — 폰에서 줄 높이가 절반으로).
- **미팅** — 지금 할 일 → 다가오는 미팅 → 일정 미정 → 전달 완료. 지난 미팅 오분류 수정.
- **미팅 전략(고객 상세)** — 주 버튼이 단계를 따른다. 분석 완료면 **[분석 보고 2차 제안 요청]** 이 주 버튼, [새 미팅 시작] 은 보조.
  지난 미팅이면 경고 한 줄 + [일정 변경] 링크(그 자리에서 해결).

## 3. 찾아서 고친 버그

- 상태 칩을 누르고 곧바로 정렬을 바꾸면 **상태 필터가 사라졌다** — React Router `setSearchParams` 콜백이 직전 렌더 값을 받는다. 지금 주소창 기준으로 고침. (E2E 반복 실행에서 드러남)
- 미팅 목록에서 초안 삭제 후 목록에 남아 있던 문제, "운영 OS" 내부 용어 노출 수정.

## 4. 하지 않은 것 (의도적으로)

- 전역 검색(Ctrl+K) — 고객 화면 검색으로 충분. 화면 요소만 늘어난다.
- 서류 미비를 할 일 큐에 올리기 — 거의 모든 고객이 해당돼 큐가 소음이 된다. 도구 화면 · 전략 화면 카드에서 이미 경고한다.
- AI 요약·추천 — 판단은 결정적 규칙으로 충분하고 설명 가능하다.
