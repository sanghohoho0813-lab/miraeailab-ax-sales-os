## 2. 추천 규칙 — 융자 3 + 투자 2

```
같은 업종만 (FILTER)  →  점수 (SCORE)  →  융자 3 + 투자 2
점수: 같은 업종 +5 · 원문 업종 표기 겹침 최대 +6 · 금액 구간 +5~0 · 확보 금액 +2 · 직접 융자 +1 · 2026년 +1
금액 구간: 5억 이내 5 > 10억 이내 4 > 20억 이내 2 > 20억 초과 0
```

- **융자·보증이 항상 앞 3칸.** 투자는 뒤 2칸.
- **같은 업종만** 본 목록에 올립니다. 규모를 맞추려고 타업종을 끌어오지 않습니다(R5 동종업계 게이트 유지).
- **한 회사가 두 칸을 먹지 않습니다.** 퓨리언스처럼 기보·중진공·퍼스트펭귄 세 건을 조달한 회사는 한 장으로 접고 `같은 회사 다른 조달: 기술보증기금 보증 5억 / 퍼스트펭귄 20억` 로 보여 줍니다.

### 사이드 "비슷한 사례도 참고하세요" — 3장

1. 같은 업종인데 3+2 에 자리가 없어 밀린 것
2. 타업종이지만 원문 업종 표기가 **두 단어 이상** 겹치는 것

(2) 에 두 단어를 요구하는 이유: "브랜드" 한 단어로는 광고회사에 식품제조 사례가 올라옵니다(실제로 올라와서 막았습니다).
