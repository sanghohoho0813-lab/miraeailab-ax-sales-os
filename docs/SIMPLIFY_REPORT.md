## 5. Same-industry Matcher 알고리즘

`recommendCases()` 를 **SCORE → 자르기** 에서 **FILTER → SCORE** 로 바꿨다.

```
1) 후보 거르기   verified & !reviewRequired & (전환 서술 있음 | 자금 관심)
2) Pool 만들기   ① 같은 업종  → 있으면 여기서 끝
                 ② (같은 업종 0건일 때만) 인접업종 — 제조↔유통↔물류 정도로만 남김
                 ③ 그래도 없으면 세부업종·제품 키워드가 실제로 겹치는 사례
3) Pool 안에서만 점수  세부분야 키워드(+3/개, 최대 6) · 같은 업종(+3) · 문제구조(+2/개)
                      · 거래형태(+1) · 전환방식(+1) · 규모↔금액(+2) · 성장단계(+1) · 자금경로(+1)
4) 기본 추천 최대 2개, 점수 4점 미만만 남으면 그것도 보여 주지 않는다
5) Pool 이 ②③ 였으면 picks 는 비우고 fallback 1개 + "동종업계 사례가 없어…" 안내를 화면에 표시
```
- `NEAR_INDUSTRY` 축소: `service → medical/food`, `food → service/distribution`, `construction/environment → …` 매핑을 삭제했다(광고회사에 병원·외식 사례가 붙던 원인). 남은 인접관계는 `manufacturing↔distribution↔logistics` 뿐이다.
- `MatchKind` 는 `sub_industry`(같은 업종·세부분야도 비슷) / `industry`(같은 업종) / `near`(업무구조 참고 사례) 세 가지로 단순화했다.
- 억지로 3개를 채우던 `primary/secondary/tertiary` 구조를 없앴다. 0개면 "같은 업종에서 검수된 사례가 아직 없습니다" 를 그대로 보여 준다.

## 10. Result Scroll Top 구현방식

`src/components/ScrollToTop.tsx` 하나로 처리한다.
- `useLocation().pathname` 이 바뀌면 `useLayoutEffect` 에서 초기화 → **브라우저가 새 화면을 그리기 전에** 실행되므로 스크롤이 내려간 상태가 한 프레임도 보이지 않는다.
- `requestAnimationFrame` 으로 한 번 더 호출한다(폰트·이미지가 늦게 들어와 높이가 변하는 경우 대비).
- `useNavigationType() === 'POP'`(뒤로가기)은 브라우저 복원을 존중한다. 단 `/meetings/:id/result` 는 예외로 언제나 최상단.
- `MeetingResultPage` 에도 `useLayoutEffect(scrollWindowTop, [meetingId])` 를 두어 같은 결과 화면 안에서 미팅이 바뀌어도 위에서 시작한다.
- `setTimeout` 은 쓰지 않았다.

## 11. 실제 Scroll Owner

**문서(`document.documentElement`)** 다. `AppShell` 은 `min-h-dvh` 래퍼와 `flex-1` main 만 쓰고 `overflow-y-auto` 컨테이너가 없다. 그래서 `window.scrollTo` + `documentElement.scrollTop` + `body.scrollTop`(Safari) 세 가지를 모두 0으로 만든다. Mobile / PC+Mobile 미리보기는 같은 앱이 iframe 안에서 돌고 iframe 은 자기 window 를 가지므로 이 컴포넌트가 프레임 안에서도 동작한다. 나중에 overflow 컨테이너를 도입하더라도 `[data-scroll-root]` 요소를 함께 0으로 만들도록 열어 두었다.

## 알려진 한계

- 폰 전략 화면 2.0 viewport, 결과 요약 1.71 viewport — 목표보다 높다(위 13~14 참고).
- 크레탑 실제 샘플은 여전히 없다. 회사명 라벨 제거는 실제 화면에서 관찰된 `영문기업명` 사례를 포함해 6가지를 고정했지만, 크레탑 전용 레이아웃 검증은 실제 파일이 필요하다.
- `service` 업종 Pool 은 78건(검수 완료)으로 넓다. 광고·마케팅 세부업종 전용 사례가 리서치 DB 에 많지 않아 "기타 B2B 소프트웨어" 사례가 올라온다. 사례 DB 가 늘면 세부업종 점수가 자연히 더 정확해진다.
